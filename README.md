# 🌟 NovaEra — Loja Virtual

> Site de e-commerce moderno e responsivo, desenvolvido com HTML e CSS puro.

---

## 📖 Sobre o Projeto

A **NovaEra** é uma loja virtual que reúne tecnologia, moda, casa e muito mais. Com design elegante em tons escuros e dourado, oferece experiência fluida em computadores, tablets e celulares. ✨

- ✅ Banner principal com imagem de fundo
- ✅ Seção de serviços e benefícios
- ✅ Produtos em destaque com preços e efeitos visuais
- ✅ Animações suaves ao passar o mouse

---

## Como Atualizar o Site

1. Edite os arquivos no computador
2. Faça o envio para o GitHub (`git push` ou faça upload direto no site)
3. Espere de **1 a 5 minutos** ⏳
4. Atualize a página do site — pronto! ✨

---

## 💡 Observações

- O arquivo principal **deve se chamar `index.html`** para funcionar no GitHub Pages
- As imagens devem estar na pasta `imagens/` com os nomes corretos
- Para mudar cores e estilos, edite o arquivo `NovaEra.css`
